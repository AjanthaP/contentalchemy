# ContentAlchemy Web Client

React + Vite frontend for the ContentAlchemy FastAPI backend.

## Quick start

```bash
cd frontend
cp .env.example .env # adjust API base URL if needed
npm install
npm run dev
```

## Production build

```bash
cd frontend
npm run build
```

The build artifacts are emitted to `frontend/dist` and can be served by any static host or reverse-proxied through FastAPI.
